# LUMEN / Wand Atelier

오리지널 마법학교 게임을 위한 **완드 코딩 실험장**. Godot 4.6.3으로 제작했습니다.
2D 평면에서 투사체와 충돌을 계산하고, 실제 3D 카메라로 뒤에서 내려다봅니다.
현재 목표는 완드 조합과 탄도 가독성 검증입니다. 파티·상점·5라운드 진행은 아직 포함하지 않습니다.

## 실행

### 로컬 PC에서 실행 (Windows / macOS / Linux)

`project.godot`는 게임 전체가 아니라 프로젝트 설정 파일입니다. **저장소 전체**를 받아야 합니다.

1. [Godot 공식 다운로드](https://godotengine.org/download/archive/4.6.3-stable/)에서 **Godot 4.6.3 Standard**를 설치합니다. .NET 버전이나 별도 SDK는 필요 없습니다.
2. 터미널에서 저장소를 복제합니다.

   ```sh
   git clone https://github.com/parkjongbin0520-spec/codex_game_proto.git
   ```

   Git을 사용하지 않으면 GitHub 저장소의 **Code → Download ZIP**으로 전체를 받아 압축을 풉니다.
3. Godot 프로젝트 관리자에서 **Import / 가져오기**를 누르고, 받은 폴더의 `project.godot`를 선택합니다.
4. 에디터가 리소스 가져오기를 마칠 때까지 기다린 후 **F5**(프로젝트 실행)를 누릅니다.

폴더에는 `project.godot`, `main.tscn`, `scripts/`, `assets/`가 함께 있어야 합니다.
`main.tscn`이 없다는 오류가 나면 설정 파일 하나만 받은 것이 아닌지 확인하세요.
네이티브 실행에는 Python, Node.js, Make, 웹 내보내기 템플릿이 필요 없습니다.

이미 Git으로 복제했다면 해당 폴더에서 다음 명령으로 업데이트합니다.

```sh
git pull --ff-only origin main
```

### 명령줄 / 웹 실행

Godot가 PATH에 있는 환경에서는:

```sh
make run
```

웹 빌드에는 Python 3와 Godot 4.6.3이 필요합니다. 별도 Python 패키지는 없습니다.

```sh
make web
make serve
```

브라우저에서 서버의 **8000번 포트**로 접속합니다. HTML 파일을 직접 열지 마세요.
WebGL 2를 지원하는 데스크톱 브라우저가 필요합니다. 첫 로딩 때 약 36MB의 WASM을 받습니다.
단일 스레드 빌드이므로 교차 출처 격리 헤더가 필요 없습니다.
`make web`은 공식 Godot 릴리스에서 필요한 템플릿만 HTTPS Range로 받고 ZIP CRC를 검증합니다.
템플릿과 에디터 캐시는 `.tools/`, 결과물은 `build/web/`에 둡니다.
`build/web/` 전체를 정적 호스팅에 올릴 수 있습니다. 현재 외부 배포는 하지 않았습니다.

## 조작

| 조작 | 동작 |
|---|---|
| 전장에서 마우스 이동 | 조준 |
| 왼쪽 버튼 클릭 / 누르고 있기 | 한 번 시전 / 순차 연속 시전 |
| 버튼 놓기 | 새 시전 중지. 이미 시작된 주문과 후속 효과는 마저 실행 |
| 슬롯 클릭 / 숫자 1–6 | 편집할 슬롯 선택 |
| 왼쪽 주문 보관함 클릭 | 선택 슬롯에 주문 장착 |
| 슬롯 드래그 / 이동 버튼 | 두 슬롯 교환 |
| 슬롯 비우기 / Delete | 선택한 주문 제거 |
| 상단 조합 예제 | 도탄·분열·충돌·타이머 예제 장착 |
| 시점 슬라이더 | 30–72도 카메라 각도 변경 |
| Space | 일시정지 / 재개 |
| R | 현재 완드 유지, 마나·탄·집계 초기화 |

편집은 기존 탄과 대기 주문을 정리하고 마나를 채웁니다. 보관함은 무한 제공하는 실험용입니다.
표적은 무한 체력 훈련용 수정입니다. 현재 적 공격·승패·저장은 없습니다.

## 주문 규칙

- 6슬롯을 왼쪽부터 읽고 빈 슬롯은 건너뜁니다. 끝에 도달하면 0.45초 재충전합니다.
- 기본 시전 간격은 0.30초입니다. 최대 마나 60, 초당 회복 15입니다.
- 수정자는 뒤의 주문을 감싸고, 동시 시전은 뒤의 두 표현식을 묶습니다.
- 충돌/시한 볼트는 **내장형 트리거 투사체**입니다. 뒤의 표현식을 소비하므로 해당 슬롯을 따로 재발사하지 않습니다.
- `[충돌 볼트][동시 시전][선더 니들][선더 니들]`은 충돌 시 두 번개탄을 실행합니다.
- 명령을 실행할 때마다 마나를 지불합니다. 부족하면 정확한 명령에서 기다리고 회복 후 이어갑니다. 이미 실행한 명령을 되풀이하지 않습니다.
- 트리거 후속 주문도 발동 시 마나를 소비합니다. 공용 FIFO 대기열을 사용합니다. 마나가 부족하면 동시 시전의 두 번째 주문도 늦게 나갈 수 있습니다.
- 도탄은 다음 투사체에 벽 반사 3회를 부여합니다. 분열은 비행 0.35초 후 3갈래로 나눕니다.
- 시한 볼트는 0.65초 후 후속 주문을 실행하며 사라집니다. 그전에 벽/표적에 막히면 후속 주문 없이 소멸합니다.
- 연결 대상이 없는 수정자는 마나만 소비합니다. 불완전한 트리거 볼트는 기본 투사체처럼 날아갑니다.

노이타에서 영감을 얻은 **프로토타입 규칙**입니다. 주문 래핑, 셔플, 모든 복사 주문, 픽셀 물리 등 전체 시스템을 재현한 버전은 아닙니다.

## 구조와 검증

- `scripts/simulation.gd`: 렌더링과 분리된 2D 탄도·충돌·실행 대기열·마나.
- `scripts/spells.gd`: 7종 스펠 데이터와 재귀적인 전위식 해석기.
- `scripts/atelier.gd`: 3D 전장·임시 마법사 모델·UI·입력·카메라.

```sh
make test
```

헤드리스 검증은 실행 순서, 빈 슬롯, 중첩 트리거, 마나 중단/재개, 반사, 분열, 타이머, 버튼 해제, 재충전을 확인합니다.
브라우저 검증은 `make serve` 이후 `node tests/browser_smoke.cjs`로 실행합니다.
`playwright`와 Chromium이 필요합니다. 일반 환경에서는 `npm install --no-save playwright` 후 `npx playwright install chromium`을 실행하세요.
시스템 Chromium 경로는 `CHROMIUM_PATH`로 지정할 수 있습니다. 결과는 `test-results/`에 저장됩니다.
웹의 `window.__wandAtelier`는 실제 시뮬레이션의 읽기 전용 진단 스냅샷입니다.

폰트는 Noto Sans CJK 부분집합입니다. 라이선스는 `assets/FONT-LICENSE.txt`에 있습니다.
새 문구에 없는 글자가 필요하면 폰트를 교체하거나 부분집합을 재생성하세요.
